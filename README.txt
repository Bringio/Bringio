BRINGIO – erste Website/PWA

Dateien:
- index.html: deutsche Startseite und Anfrageformular
- manifest.webmanifest: PWA-Metadaten
- sw.js: einfacher Offline-Cache
- icon.svg: App-Symbol

Wichtig:
Das Anfrageformular ist derzeit nur eine lokale Demo. Es versendet und speichert keine echten Bestellungen.
Vor dem Live-Betrieb bitte ein echtes Formular/Backend, Datenschutz, Impressum, Kontakt, Preis- und Zahlungsablauf ergänzen.

Kostenlos veröffentlichen:
1. GitHub-Konto erstellen/anmelden.
2. Neues öffentliches Repository namens bringio erstellen.
3. Diese Dateien aus dem ZIP ins Stammverzeichnis hochladen.
4. In Settings > Pages: Deploy from a branch auswählen, Branch main und Folder /(root) speichern.
5. Die angezeigte GitHub-Pages-Adresse öffnen und testen.

Für eine echte Bestellannahme muss anschließend ein Formularanbieter oder Backend verbunden werden.
