BRINGIO – vollständiges Website-Paket mit WhatsApp-Anfrage

DATEIEN
- index.html: Website und Bestell-/Anfrageformular mit WhatsApp-Weiterleitung
- manifest.webmanifest: PWA-Metadaten
- sw.js: einfacher Offline-Cache
- icon.svg: App-Symbol

WHATSAPP
Das Formular öffnet WhatsApp mit einer vorbereiteten Nachricht an die BRINGIO-Nummer.
Der Kunde muss die Nachricht in WhatsApp selbst absenden.
Die hinterlegte Nummer lautet: +49 177 7064275.

GITHUB
Dieses ZIP enthält alle Website-Dateien. Entpacke es und lade die vier Dateien
(index.html, manifest.webmanifest, sw.js, icon.svg) in das Stammverzeichnis
des Repositorys hoch. README.txt ist nur eine Anleitung und muss nicht auf
der Website veröffentlicht werden.
Wenn GitHub fragt, ob bestehende Dateien ersetzt werden sollen, bestätige das.
Danach kontrolliere Settings > Pages und warte auf das erfolgreiche Deployment.

WICHTIG
Die WhatsApp-Weiterleitung funktioniert, aber die Website ist noch kein
vollständiges Shopsystem. Sie nimmt nur Anfragen entgegen; sie verarbeitet
keine Zahlungen und bestätigt keine verbindlichen Bestellungen.
Vor dem offiziellen Betrieb müssen insbesondere Impressum, Datenschutz,
Kontaktangaben, Preis-/Gebührenregeln und die rechtlichen/steuerlichen
Voraussetzungen geprüft und ergänzt werden.
